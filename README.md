# QPOS — Point of Sale & Retail Management System

Web-based POS system for small-to-medium minimarkets and convenience stores.

**Tech**: React 19, TypeScript 6, Vite 8, Tailwind CSS 4, Express.js 4, Prisma 7 (PostgreSQL)

**Frontend** → `https://www.qpos.shop` (Vercel)  
**Backend API** → `https://api.qpos.shop` (VPS + Docker)

## Quick Start

```bash
npm install
npm run dev              # Frontend HMR (localhost:5173)
npm run dev:server       # Backend (localhost:3000)
```
